# Производственный календарь

## Описание проекта

Учебный проект по дисциплине «Объектно-ориентированное программирование».

Программа реализует базовую модель производственного календаря на один год. Она позволяет определять тип календарного дня, учитывать праздники и предпраздничные дни, а также рассчитывать количество рабочих дней и часов за выбранный период.

## Используемые технологии

- Java 21
- Maven
- JUnit 5
- IntelliJ IDEA

## Реализованные возможности

- Определение типа календарного дня:
    - рабочий день;
    - выходной;
    - праздничный;
    - предпраздничный;
    - отпуск.
- Добавление праздников в календарь.
- Добавление предпраздничных дат.
- Получение списка праздников.
- Подсчёт рабочих дней и часов за произвольный период.
- Подсчёт рабочих дней и часов за квартал и год.
- Вывод календаря выбранного месяца с типами дней.
- Проверка корректности входных данных и обработка ошибок.

## Структура проекта

- `DayRule` — интерфейс, определяющий правило расчёта рабочих часов.
- `DayType` — перечисление типов календарных дней.
- `Holiday` — запись, представляющая праздничный день.
- `CalendarException` — собственное исключение проекта.
- `ProductionCalendar` — основной класс производственного календаря.
- `Main` — консольное приложение для демонстрации возможностей.

## Запуск проекта

Для запуска необходима Java 21 и Maven.

Сборка проекта:

```bash
mvn clean package
```

Запуск тестов:

```bash
mvn test
```

Запуск приложения:

```bash
mvn exec:java -Dexec.mainClass="ru.student.productioncalendar.Main"
```

## Тестирование

Для проверки работы программы используются автоматические тесты JUnit 5, охватывающие определение типов дней, добавление праздников, подсчёт рабочих дней и часов, а также обработку некорректных данных.

## Ограничения

Проект представляет собой упрощённую учебную модель производственного календаря. Автоматический учёт официальных переносов выходных и полный перечень государственных праздников не реализованы.
